## 🎯 Об игре

Физическая аркада, где нужно аккуратно ставить кубики друг на друга. Платформа автоматически наклоняется, усложняя задачу с каждым уровнем!

### Особенности:
- 🤖 **Режим "Игрок vs Компьютер"** — сразись с ИИ
- 👥 **Режим "Игрок vs Игрок"** — играй с другом
- 📐 **Динамическая сложность** — чем выше башня, тем сильнее качает
- 🏆 **Система рекордов** — сохраняется в браузере
- 📱 **Адаптивный дизайн** — работает на телефонах и ПК
- 🔊 **Звуковые эффекты** — генерируются через Web Audio API
- ❄️ **Анимации** — снежинки, плавное появление блоков
- 🌐 **Офлайн-режим** — работает без интернета
- 📄 **Один HTML-файл** — никаких зависимостей, кроме Matter.js

---

## 🕹️ Управление

### На компьютере:
- **Мышь** — двигай блок влево/вправо
- **Клик** — поставить блок
- **R** — сбросить фазу наклона
- **Space** — поставить блок (альтернатива)

### На телефоне:
- **Касание и перетаскивание** — двигай блок
- **Тап** — поставить блок
- **Кнопка ⟳** — сбросить фазу наклона

## 🚀 Как играть

### Онлайн:
Просто открой `index.html` в браузере или перейди по ссылке GitHub Pages.

### Офлайн:
1. Скачай репозиторий (Code → Download ZIP)
2. Распакуй архив
3. Открой `index.html` в любом современном браузере
4. Играй! 🎮
